Projects and files

Projects keep each business's or client's labels together, so you can find them again quickly.

Projects

  • Create a project with + New project... on the welcome screen, or File > New Project.
  • Select a project on the welcome screen to see its labels, then click New label... to add one to it.
  • Right-click a project to rename it, show it in the file manager, or move it to the Trash.
  • Right-click a label in a project to open, rename, duplicate or remove it.

Each project is an ordinary folder in Documents/gLabels Plus Projects. Back it up, copy it to another computer or share it like any other folder. Put images and CSV files used by the labels in the same folder.

Label files

  • Labels are saved as .glabels files (compressed XML). They hold the product, the objects, the merge settings and the variables.
  • [[Ctrl+N]] new, [[Ctrl+O]] open, [[Ctrl+S]] save, [[Ctrl+Shift+S]] save as, [[Ctrl+W]] close.
  • Recently opened labels appear on the welcome screen. Clear the list in Preferences > General.
  • Labels made with gLabels 3.x for Linux can be opened directly.
  • If you close a label with unsaved changes, gLabels Plus asks whether to save it first.
Images and merge files are linked, not stored inside the .glabels file. When you share a label, share those files too.
