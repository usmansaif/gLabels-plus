Substitution field syntax

A substitution field is replaced with a value when the label is printed. Fields can name a merge column or a variable, and can be used in text, barcodes, image file names and colors.

Basic form

${FIELD}

For example ${FIRST_NAME}. Modifiers come after a colon, and several can be chained:

${FIELD:modifier:modifier}

Default value: =

Used when the field is empty or missing.

${COUNTRY:=Pakistan}

To use :, } or \ in a default value, put a backslash in front: \:, \}, \\.

New line only if not empty: n

Puts the value on a new line, but only if it has a value, so empty address lines don't leave gaps:

${NAME}
${ADDR1}${ADDR2:n}
${CITY} ${ZIP}

Number and text format: %

A printf-style format: % [flags] [width] [.precision] type.

FieldValuePrints
${n:%05d}4200042
${price:%.2f}3.53.50
${n:%+d}7+7
${n:%X}255FF
${name:%.10s}Christopher ColumbusChristophe
${name:%-12s}|AliAli         |

Types

TypeMeaning
d, iWhole number
uUnsigned whole number
f, FDecimal number
e, EScientific notation
g, GDecimal or scientific, whichever is shorter
x, XHexadecimal (lower or upper case)
oOctal
sText

Flags

FlagMeaning
-Align left within the width
+Always show the sign of a number
spacePut a space in front of positive numbers
0Pad numbers with zeros instead of spaces

Combining modifiers

${qty:=0:%03d}

Prints the quantity as three digits, or 000 if it is empty.
