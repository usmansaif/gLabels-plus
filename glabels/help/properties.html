Object properties reference

The Object properties panel on the right of the Edit page shows settings for the selected object. Its tabs depend on the kind of object.

Show or hide the panel with View > Object Properties Panel. Turn View > Units in Properties on to show unit names next to values, such as 25.40 mm.

Text tab

SettingWhat it does
Family, Size, Style, ColorThe font. Type in Family to search fonts.
AlignmentHorizontal (left, center, right) and vertical (top, middle, bottom) alignment in the box.
Line spacingSpace between lines; 1 is normal.
Wrap modeWord, Anywhere or None.
Allow printing to shrink text to fit objectLong values are printed smaller so they fit the box.
EditorThe text itself, with an Insert substitution field button.

Barcode tab

SettingWhat it does
TypeThe barcode symbology, grouped by library.
Show textPrints the human-readable text.
ChecksumAdds a check digit, when the type allows it.
ColorColor of the bars.
Barcode dataThe data to encode, with an Insert substitution field button.

Image tab

File: choose an image with Browse..., or Use substitution field to take the file name from a merge column.

Line/Fill tab

Line width and color; Fill color (boxes and ellipses).

Position/Size tab

SettingWhat it does
X, YPosition of the object's top-left corner from the top-left corner of the label.
Width, HeightSize of the object.
Lock aspect ratioKeeps width and height in proportion.
Length, AngleFor lines.
Original size, ResetFor images: shows the image's own size and restores it.

Shadow tab

Turn the shadow on and set its X offset, Y offset, Color and Opacity.

Colors

Every color button opens a palette with standard colors, your recently used colors and a custom color picker. A color can also come from a merge field or variable, for example a column that holds #FF0000.
