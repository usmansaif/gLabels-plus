Text

Text objects can hold one line or a whole paragraph, mixed with merge fields and variables.

Adding and editing text

  • Press [[T]] and click on the label to start typing, or drag to set the width of the text box.
  • To edit existing text, double-click it, or select it and press [[Enter]] or [[F2]]. You type straight onto the label.
  • Press [[Enter]] for a new line. Press [[Ctrl+Enter]] or click elsewhere to finish. [[Esc]] cancels your changes.
  • You can also edit the text in the Editor box of the Text tab in the properties panel.

Font

  • Quick font search: type any part of a font name in the Family box, for example mono or sans. Matches are shown in their own typeface. Press [[Enter]] or click to apply.
  • Set the size, style (bold, italic, underline) and color.

Layout

  • Alignment: left, center or right, and top, middle or bottom within the box.
  • Line spacing: 1 is normal; larger values spread the lines apart.
  • Wrap mode: Word wraps between words, Anywhere can break inside a word, None keeps each line on one line.
  • Allow printing to shrink text to fit object: long merged values are made smaller so they never overflow the box. Very useful with mail merge.

Inserting fields

Use the Insert substitution field button on the Text tab to add a merge field or variable at the cursor, such as ${NAME}. When printing, each field is replaced with its value. See Substitution field syntax for formatting options.

Urdu and right-to-left text

The Noto Nastaliq Urdu font (regular and bold) is built in, so Urdu is shaped and printed in true Nastaliq on every computer, even if the font isn't installed. Type urdu in the Family box to pick it. The Left, Center and Right buttons align right-to-left text exactly as shown, and you can mix Urdu with English, numbers and barcodes.

If text looks different on another computer, that computer probably doesn't have the font. Choose a font that is installed on both, or one of the built-in fonts.
