Adding and arranging objects

A label is built from objects: text, barcodes, images, boxes, lines and ellipses. This page covers creating, selecting and arranging them.

Drawing tools

ToolKeyHow to use it
Select[[V]]Select, move and resize objects. This is the normal mode.
Text[[T]]Click to start typing, or drag to set the width of the text box.
Box[[R]]Drag to draw a rectangle.
Line[[L]]Drag from one end to the other.
Ellipse[[O]]Drag to draw an ellipse or circle.
Image[[I]]Drag a frame, then choose the image file in the properties panel.
Barcode[[B]]Drag a frame, then type the data. See Barcodes.
Measure[[M]]Drag between two points to measure. See Measuring.

After you draw an object, gLabels Plus switches back to the Select tool. You can change any of these keys in Tools > Keyboard Shortcuts.

Selecting

  • Click an object to select it. [[Ctrl]]+click adds an object to the selection, or removes it.
  • Drag on an empty part of the label to select every object inside the rectangle. Hold [[Ctrl]] to add them to the current selection.
  • [[Ctrl+A]] selects everything; Edit > Un-select All clears the selection. [[Esc]] also clears it.
  • Click a row in the Objects panel to select objects that are hidden under others.
  • Locked objects can't be selected on the canvas. Unlock them in the Objects panel.

Moving and resizing

  • Drag a selected object to move it. A tooltip shows the live position.
  • To resize a selected object, drag a corner or any point along an edge: the pointer changes to a resize arrow when you are over one. Corners change the width and height together, edges change one side. This works for text, barcodes, images, boxes and ellipses, also when rotated; drag either end of a line. Hold [[Ctrl]] while resizing to keep the proportions (or, if Lock aspect ratio is on, to free them).
  • To resize several objects or a whole group at once, select them all (drag a box round them, [[Ctrl]]+click, or click the group in the Objects panel). A dashed box appears round the selection with a handle at each corner: drag a corner to scale everything together with its proportions kept. The opposite corner stays where it is, and text sizes and line widths scale with it. Locked objects in the selection turn this off.
  • The arrow keys nudge the selection one step; hold [[Shift]] for ten steps.
  • [[Ctrl]]+mouse wheel zooms; [[Shift]]+mouse wheel scrolls sideways.
  • For exact values, type the X, Y, width and height in the Position/Size tab of the properties panel.
  • Objects snap to other objects and to the label while you drag. Hold [[Ctrl]] to turn snapping off for that drag. See Smart guides.

Cut, copy, paste, duplicate and delete

  • [[Ctrl+X]], [[Ctrl+C]] and [[Ctrl+V]] cut, copy and paste. You can paste into another open label.
  • [[Ctrl+D]] duplicates the selection (from the Objects panel).
  • [[Delete]] or [[E]] deletes the selection.
  • [[Ctrl+Z]] undoes and [[Ctrl+Y]] (or [[Ctrl+Shift+Z]]) redoes. Every change can be undone.

Stacking order

Objects higher in the list are drawn on top. Use Objects > Order or the right-click menu:

  • Bring Forward [[Ctrl+]]] and Send Backward [[Ctrl+[]] move one layer at a time.
  • Bring To Front [[Ctrl+Shift+]]] and Send To Back [[Ctrl+Shift+[]] move all the way.
  • You can also drag rows in the Objects panel.

Rotating and flipping

  • Objects > Rotate/Flip: rotate left or right by 90°, flip horizontally or vertically.
  • Type any angle into the rotation box on the toolbar, or in the Position/Size tab.

Curved text for round labels

Text can follow an arc, a circle or a wave. Select a text object and choose a Path in the Text tab of the properties panel:

  • Arc (top): the text runs left to right over the top, letters standing on the curve. Use it for a business name around the top of a round sticker.
  • Arc (bottom): the text runs left to right under the bottom, so it still reads the right way up. Use it for a website or weight along the bottom.
  • Circle: the text goes all the way round, starting at the top.
  • Wave: the text follows one wave across the box.
  • Rectangle: the text runs round the edges of the box, starting at the top.

The curve fits inside the text box. For a round label, make the text box the same size as the label and center it: the text then follows the edge. Make the box smaller to move the text in, or flatter to make a gentler arc.

Put text on a shape you drew

  1. Draw a circle or ellipse ([[O]]), a box ([[R]]) or a line ([[L]]) where you want the text to go.
  2. Select the text and the shape together ([[Ctrl]]+click).
  3. Choose Objects > Put Text on Shape (also in the right-click menu).

The text takes the shape's position, size and rotation: it curves along a circle or ellipse, runs round a box, or stands on a line. The two are grouped so they move together. The shape is an ordinary object, so you can leave it as a printed border or delete it.

Fine-tuning curved text

  • Start angle turns the text round the curve, one degree at a time. Drag the slider, or type an angle; positive values move it clockwise.
  • Distance from edge moves the text in from the edge of the box or shape. Use a negative value to put the text round the outside of a circle.
  • Alignment sets where the text sits on the curve: Center puts it in the middle of the arc (or on top of the circle).
  • Letter spacing adds space between letters, in points, to spread a short word around the curve. It works on straight text too.
  • Curved text is a single line. Wrap mode, line spacing and vertical alignment are turned off while a path is chosen.
  • With Allow printing to shrink text on, long merged text is made smaller until it fits along the curve.
The round stickers under File > New from Sample > Stickers use curved text, ready to edit.

Inserting symbols

Tools > Insert Symbol ([[Ctrl+Shift+Y]]) opens a set of solid black symbols made for thermal label printers. They stay sharp even when small, because they have no grey or thin lines.

  • Handling: Fragile, This Way Up, Keep Dry, Keep Away from Heat, Do Not Stack, Temperature, Recyclable, Handle with Care.
  • Food: Keep Refrigerated, Vegetarian and Non-Vegetarian marks, Gluten Free, Spicy, Microwave Safe, Natural, Hot Drink, Cupcake.
  • Contact: Phone, Mobile, Email, Website, Location, Opening Hours, Date, Person, Message, Home.
  • Shop & delivery, Marks & shapes and Arrows: delivery truck, package, price tag, discount, gift, cut here, stars, hearts, ticks, check boxes, warning, arrows and more.

Pick a symbol (search or choose a category), set the Size, then press Insert or double-click it. The symbol is added to the middle of the label and selected, ready to move. The window stays open so you can add more; close it when you're done.

Symbols are images saved inside the label file, so they print the same on any computer. Resize them like any image.

Aligning and centering

Objects > Alignment lines objects up by their left, center, right, top, middle or bottom edges. Choose what they align to at the bottom of the same menu:

  • Selection: the outer edges of all the selected objects.
  • Last selected object: the other objects move to match it.
  • Label: align to the label's edges, even with just one object selected.

Objects > Center centers the selection on the label horizontally, vertically or both.

Set your preferred alignment reference once in Preferences > Editor.

Right-click menu

Right-click an object for quick access to Edit Text, Order, Rotate/Flip, Alignment, Center, Cut, Copy, Paste and Delete.
