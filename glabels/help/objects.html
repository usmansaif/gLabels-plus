Adding and arranging objects

A label is built from objects: text, barcodes, images, boxes, lines and ellipses. This page covers creating, selecting and arranging them.

Drawing tools

ToolKeyHow to use it
Select[[V]]Select, move and resize objects. This is the normal mode.
Text[[T]]Click to start typing, or drag to set the width of the text box.
Box[[R]]Drag to draw a rectangle.
Line[[L]]Drag from one end to the other.
Ellipse[[O]]Drag to draw an ellipse or circle.
Image[[I]]Drag a frame, then choose the image file in the properties panel.
Barcode[[B]]Drag a frame, then type the data. See Barcodes.
Measure[[M]]Drag between two points to measure. See Measuring.

After you draw an object, gLabels Plus switches back to the Select tool. You can change any of these keys in Edit > Keyboard Shortcuts.

Selecting

  • Click an object to select it. [[Ctrl]]+click adds an object to the selection, or removes it.
  • Drag on an empty part of the label to select every object inside the rectangle. Hold [[Ctrl]] to add them to the current selection.
  • [[Ctrl+A]] selects everything; Edit > Un-select All clears the selection. [[Esc]] also clears it.
  • Click a row in the Objects panel to select objects that are hidden under others.
  • Locked objects can't be selected on the canvas. Unlock them in the Objects panel.

Moving and resizing

  • Drag a selected object to move it. A tooltip shows the live position.
  • Drag one of the handles to resize. Hold [[Ctrl]] while resizing to keep the proportions (or, if Lock aspect ratio is on, to free them).
  • The arrow keys nudge the selection one step; hold [[Shift]] for ten steps.
  • [[Ctrl]]+mouse wheel zooms; [[Shift]]+mouse wheel scrolls sideways.
  • For exact values, type the X, Y, width and height in the Position/Size tab of the properties panel.
  • Objects snap to other objects and to the label while you drag. Hold [[Ctrl]] to turn snapping off for that drag. See Smart guides.

Cut, copy, paste, duplicate and delete

  • [[Ctrl+X]], [[Ctrl+C]] and [[Ctrl+V]] cut, copy and paste. You can paste into another open label.
  • [[Ctrl+D]] duplicates the selection (from the Objects panel).
  • [[Delete]] or [[E]] deletes the selection.
  • [[Ctrl+Z]] undoes and [[Ctrl+Y]] (or [[Ctrl+Shift+Z]]) redoes. Every change can be undone.

Stacking order

Objects higher in the list are drawn on top. Use Objects > Order or the right-click menu:

  • Bring Forward [[Ctrl+]]] and Send Backward [[Ctrl+[]] move one layer at a time.
  • Bring To Front [[Ctrl+Shift+]]] and Send To Back [[Ctrl+Shift+[]] move all the way.
  • You can also drag rows in the Objects panel.

Rotating and flipping

  • Objects > Rotate/Flip: rotate left or right by 90°, flip horizontally or vertically.
  • Type any angle into the rotation box on the toolbar, or in the Position/Size tab.

Aligning and centering

Objects > Alignment lines objects up by their left, center, right, top, middle or bottom edges. Choose what they align to at the bottom of the same menu:

  • Selection: the outer edges of all the selected objects.
  • Last selected object: the other objects move to match it.
  • Label: align to the label's edges, even with just one object selected.

Objects > Center centers the selection on the label horizontally, vertically or both.

Set your preferred alignment reference once in Preferences > Editor.

Right-click menu

Right-click an object for quick access to Edit Text, Order, Rotate/Flip, Alignment, Center, Cut, Copy, Paste and Delete.
