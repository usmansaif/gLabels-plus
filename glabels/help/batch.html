Command-line printing

glabels-batch-qt prints a label file or exports it to PDF without opening the app. Use it in scripts, scheduled jobs, or from another program.

Usage

glabels-batch-qt [options] FILE

FILE is a .glabels file. Use - to read the label from standard input.

Options

OptionMeaning
-p, --printer <printer>Send to this printer instead of a PDF file.
-o, --output <file>Output PDF file name (default output.pdf); - writes to standard output.
-i, --input <source>Use this merge file instead of the one saved in the label; - reads standard input.
-s, --sheets <n>Number of full sheets for labels without merge data (default 1).
-c, --copies <n>Copies of each record (default 1).
-a, --collateCollate merge copies.
-g, --groupStart each merge group on a new page.
-f, --first <n>Start at label position n (default 1).
-l, --outlinesPrint label outlines.
-m, --crop-marksPrint crop marks.
-r, --reversePrint a mirror image.
-D, --define <var>=<value>Set the starting value of a user variable.
-v, --version, -h, --helpShow the version or help.

Examples

Export to PDF:

glabels-batch-qt -o labels.pdf address.glabels

Print today's orders to a label printer:

glabels-batch-qt -p Zebra_ZD420 -i orders-today.csv shipping.glabels

Continue serial numbers from 501, two sheets:

glabels-batch-qt -D serial=501 -s 2 -o tags.pdf asset-tags.glabels
On Linux, glabels-batch-qt needs a graphical session to read font information. On a server without a display, run it with xvfb-run glabels-batch-qt ....
