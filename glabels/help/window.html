The main window

gLabels Plus has a welcome screen and five pages for each open label. Switch pages with the buttons at the bottom left or with [[Ctrl+1]] to [[Ctrl+4]] and [[Ctrl+P]].

Welcome screen

Shown when you start gLabels Plus. From here you can:

  • Create a new label or open an existing one.
  • Reopen a recent label. Right-click a recent label to remove it from the list.
  • Create and browse projects.
  • Use the links at the bottom: Preferences, Keyboard shortcuts, Help, What's New and the gLabels Plus website.

The five pages

PageShortcutWhat it is for
Edit[[Ctrl+1]]The label canvas where you draw and arrange objects. See Adding and arranging objects.
Properties[[Ctrl+2]]The product (label stock) this label uses, its size and layout, orientation, and similar products. See Products.
Merge[[Ctrl+3]]Connect a CSV or other text file so every row prints as its own label. See Mail merge.
Variables[[Ctrl+4]]Counters and other values that change from label to label. See Variables.
Print[[Ctrl+P]]Preview, choose where to start on the sheet, copies and print options. See Printing.

The Edit page

  • Toolbars along the top: file commands, the drawing tools (Select, Text, Box, Line, Ellipse, Image, Barcode, Measure), arrange commands, the page selector, the units selector, the rotation box and the zoom box.
  • Rulers along the top and left of the label. Click the corner where they meet to switch units.
  • Objects panel: every object on the label, top-most first. See Objects panel, layers and groups.
  • Object properties panel: settings for the selected object. See Object properties reference.
  • Status bar at the bottom: cursor position and zoom level.
Hover over any toolbar button to see what it does and its keyboard shortcut.

Showing and hiding parts of the window

Use the View menu to show or hide the rulers, grid, markup lines, the Objects panel, the Object properties panel and each toolbar. Choose the icon size and whether buttons show text in Preferences > Window Layout.

Zooming

  • [[Ctrl++]] and [[Ctrl+-]] zoom in and out.
  • View > Zoom 1 to 1 shows the label at its real size; Zoom to Fit fills the window.
  • Type a value such as 250 into the zoom box on the toolbar.
