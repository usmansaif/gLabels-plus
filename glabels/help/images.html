Images, boxes, lines and ellipses

Images

  1. Press [[I]] (or click Image) and drag a frame on the label.
  2. In the Image tab of the properties panel, click Browse... and choose a file.
  • Supported formats: PNG, JPEG, GIF, BMP, SVG, and the PBM, PGM, PPM, XBM and XPM formats.
  • SVG logos stay sharp at any size and are ideal for printing.
  • For photos, use an image of at least 300 pixels per inch at the printed size.
  • PNG images with transparency print with a see-through background.
  • Click Reset in the Position/Size tab to return an image to its original size, and tick Lock aspect ratio so it is never stretched.
  • Use substitution field chooses a different image file for every label from a merge column that holds file names or paths, for example product photos.
Images are linked, not copied into the label file. Keep image files next to your .glabels file (or in the same project folder) so the label still finds them after you move or share it.

Boxes

Press [[R]] and drag. In the Line/Fill tab, set the outline width and color, and the fill color. Set the line width to 0 for a box with no outline, or the fill to transparent for an outline only. Boxes make good borders and colored bands behind text.

Ellipses and circles

Press [[O]] and drag. Ellipses have the same line and fill settings as boxes. For a perfect circle, type the same width and height in the Position/Size tab.

Lines

Press [[L]] and drag from one end to the other. Set the width and color in the Line/Fill tab, and the exact length and angle in the Position/Size tab.

Shadows

Text, boxes, ellipses, lines, images and barcodes can have a drop shadow. Turn it on in the Shadow tab and set its X and Y offset, color and opacity.
