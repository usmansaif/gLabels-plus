Mail merge from CSV

Mail merge prints one label for every row of a spreadsheet: address labels, name badges, price tags or thousands of unique barcodes.

1. Prepare your data

  • In Excel, LibreOffice Calc or Google Sheets, put one record per row and give each column a heading in the first row, such as NAME, PRICE, SKU.
  • Save or download the sheet as CSV (comma separated values). Choose UTF-8 encoding if asked, so accented and Urdu characters are kept.
Column headings without spaces or punctuation (FIRST_NAME rather than First name:) are easiest to use in fields.

2. Connect the file

  1. Open the Merge page ([[Ctrl+3]]).
  2. Choose the Format. Pick a format ending in keys on line 1 if your first row holds column headings.
  3. Click Browse... and choose your file. The records appear in the table.
  4. Untick any rows you don't want to print, or use Select all and Unselect all.
  5. If you change the file in your spreadsheet program, click Reload.
FormatUse for
Comma Separated Values (CSV)Most spreadsheet exports.
Tab Separated Values (TSV)Text copied from a spreadsheet, or data containing commas.
Semicolon Separated ValuesCSV files saved by Excel in countries that use a decimal comma.
Colon Separated ValuesSome system and database exports.

Without keys on line 1, columns are named by number: ${1}, ${2} and so on.

3. Put fields on the label

  • In a text object, click Insert substitution field in the properties panel and pick a column. A field such as ${NAME} is inserted. You can mix fields with ordinary text: Price: ${PRICE}.
  • For a barcode, insert a field in the Barcode data. Every row prints its own barcode.
  • For an image, use Use substitution field with a column of image file names.

Fields can be formatted, given default values, or placed on their own line only when they have a value. See Substitution field syntax.

4. Preview real records

Turn on View > Merge Preview > Preview Merge Data to show real records on the label instead of field names. Step through records with First, Previous ([[Alt+PgUp]]), Next ([[Alt+PgDown]]) and Last, to check that long names fit.

5. Print

On the Print page, each selected record becomes one label. Set Copies to print each record several times, choose whether copies are collated, and whether each merge group starts on a new page.

Troubleshooting

  • All data appears in one column: the wrong separator is selected. Try Semicolon or Tab.
  • Field names are printed instead of values: the name in ${...} must match the column heading exactly, including upper and lower case.
  • Strange characters: save the CSV file as UTF-8.
  • Leading zeros disappear (for example in ZIP codes or barcodes): format the column as Text in your spreadsheet before saving as CSV.
