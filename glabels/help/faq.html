Troubleshooting and FAQ

Printing

The print is shifted or doesn't line up with the labels

Turn off Fit to page or scaling in the printer settings, check that the paper size matches (A4 or Letter), and print a test on plain paper with outlines. See Getting the alignment right.

Only part of the label prints, or the edges are cut off

Most printers can't print to the very edge of the paper. Keep text inside the markup lines (View > Markup).

My thermal printer skips labels or prints across two labels

Make the driver's paper size exactly the label size and calibrate the printer's label sensor. See Thermal and roll printers.

How do I use a sheet that is partly used?

On the Print page, click the first free label in the preview. Printing starts there.

Can I make a PDF?

Yes. Choose Print to file (PDF) as the destination on the Print page.

Barcodes

The barcode doesn't scan

Make it bigger, leave empty space on both sides, print in black on white, and check that the data suits the type. See Getting barcodes to scan.

I can't find QR Code or another barcode type

Some types come from optional libraries (Zint, GNU Barcode, libqrencode). Install a build of gLabels Plus that includes them.

Mail merge

All my data shows up in one column

Choose the format that matches your file's separator (comma, semicolon or tab). Excel in many countries saves CSV files with semicolons.

The label prints ${NAME} instead of the name

The field name must exactly match the column heading, including upper and lower case, and the format must be one with keys on line 1.

Long names don't fit

Turn on Allow printing to shrink text to fit object in the Text tab, then check the longest records with Merge Preview.

Text and fonts

The font looks different on another computer

That computer doesn't have the font installed. Install it there, or use a common font.

Urdu letters are not joined

Choose the built-in Noto Nastaliq Urdu font (type urdu in the Family box).

Products

My label sheet isn't in the list

Search by size instead of part number, check Also sold as, or create it with the Product Template Designer.

I chose the wrong product

Click the page selector on the toolbar or press [[Ctrl+Shift+P]] to switch. Your objects are kept.

Files

An image is missing when I open a label

The image file was moved or not copied with the label. Choose it again in the Image tab, and keep images in the same folder or project as the label.
