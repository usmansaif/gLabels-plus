Objects panel, layers and groups

The Objects panel lists every object on the label from top-most to bottom-most. Use it to name, lock, group and reorder objects.

The list

  • Click a row to select that object; [[Ctrl]]+click and [[Shift]]+click select several.
  • Drag rows to change the stacking order.
  • Show or hide the panel with View > Objects Panel.

Naming objects

Double-click a row, or select it and press [[F2]], then type a name such as Price or Logo. Names make large labels much easier to work with.

Locking

Click the lock column next to an object. A locked object can't be selected or moved on the canvas, which is useful for backgrounds and borders. Click the lock again to unlock it.

Groups

  • Select some objects and press [[Ctrl+G]] to put them in a collapsible group.
  • Select the group to move, align or lock all of its objects at once.
  • Expand the group to select one object inside it.
  • [[Ctrl+Shift+G]] ungroups.

Panel toolbar and right-click menu

The toolbar at the top of the panel and the right-click menu offer: rename, lock, duplicate ([[Ctrl+D]]), group, ungroup, move up and down, and delete. Each button is enabled only when it applies to the selection.
