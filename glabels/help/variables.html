Variables and counters

Variables are values you define yourself. They can stay the same, or count up on every label, which is perfect for serial numbers, ticket numbers and asset tags.

Creating a variable

  1. Open the Variables page ([[Ctrl+4]]) and click Add.
  2. Enter a Name, for example serial. Names start with a letter or underscore and contain only letters, digits and underscores.
  3. Choose a Type and an initial Value.
  4. For numbers, choose how it increments and the step size.

Use Edit and Delete to change or remove variables.

Types

TypeExample valueNotes
StringBatch AText that stays the same on every label.
Integer1001Whole numbers; can increment.
Floating Point0.5Decimal numbers; can increment.
Color#0055AAUse as the color of text, lines, fills or barcodes.

Increment

SettingThe value increases...
Nevernever; it is a constant.
Per itemon every label printed.
Per copyafter each copy of a merge record.
Per pageonce for each printed sheet.

Using a variable

Insert it like a merge field with Insert substitution field, for example No. ${serial}. In a barcode, ${serial} gives each label a unique barcode.

Example: numbered asset tags

  1. Add an Integer variable tag with value 1, increment Per item, step 1.
  2. Add text ASSET-${tag:%05d}. The %05d pads it to five digits: ASSET-00001, ASSET-00002...
  3. Add a Code 128 barcode with data ASSET-${tag:%05d}.
  4. On the Print page, print as many sheets as you need.
When printing from the command line you can set a variable's starting value with --define tag=501. See Command-line printing. If a merge column and a variable have the same name, the merge column wins.
