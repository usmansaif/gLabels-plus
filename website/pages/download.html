How do I build gLabels Plus from source?

On Linux, macOS or Windows (Git Bash), install CMake 3.22+, a C++20 compiler and Qt 6.2+, then run:

Terminal
git clone https://github.com/usmansaif/gLabels-plus.git
cd gLabels-plus
./build.sh --deps          # install build dependencies (first time only)
./build.sh                 # configure and build (Release)
./build/glabels/glabels-qt # run

Platform guides: Linux · Windows · macOS

After installing

  1. Open gLabels Plus and click New label... on the welcome screen.
  2. Pick your product: search a part number such as avery 5160, or choose a barcode label size.
  3. Add objects with single keys: T Text, B Barcode, I Image.
  4. Print from the Print page, or merge a CSV file to print one label per row.
